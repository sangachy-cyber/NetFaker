# 📘 网络轨迹生成系统：端到端预处理全流程规范  
## v1.3 —— 安全 · 自适应 · 可解释 · 生产就绪（完整修订版）

> **目标**：将原始 HoloWAN 探针文件（`.txt`）转化为结构化训练数据，并输出质量评估报告。  
> **设计哲学**：
> - 每个处理阶段 = 一个**纯函数**（无副作用、可测试、可并行）
> - 主流程仅做**调度 + I/O**
> - **首窗口用于冷启动初始化，不参与训练损失**
> - **按 trace_id 整体划分数据集**（避免跨 split 局部特征依赖）
> - **特征与窗口数据严格同分布（归一化后一致）**
> - **所有中间状态可序列化、可审计**

## 3. 关键类型定义（建议放入 `src/preprocessing.py`）

🟢 **问题修复**：原 v1.2 中 `stage8` 直接输出 `WindowMetaNormed`，但此时尚未计算 `cond` 和 `keep`，逻辑断裂。  
🟢 **解决方案**：引入中间类型 `WindowMetaRenamed`，使各阶段职责清晰。

```python
from typing import TypedDict, List
import pandas as pd
import numpy as np

class WindowMetaRaw(TypedDict):
    window: pd.DataFrame          # columns: timestamp, delay_up, delay_down, loss_up, loss_down
    is_first: bool
    start_time: float             # seconds since epoch
    trace_id: str

class WindowMetaRenamed(TypedDict):  # ← 新增中间类型（v1.3）
    window: pd.DataFrame          # columns: timestamp, del_up, del_dn, loss_up, loss_dn
    is_first: bool
    start_time: float
    trace_id: str

class WindowMetaNormed(TypedDict):
    window: pd.DataFrame          # columns: timestamp, del_up, del_dn, loss_up, loss_dn
    is_first: bool
    start_time: float
    trace_id: str
    cond: np.ndarray              # shape=(23,) → [22 floats + 1 int (stored as float)]
    keep: bool                    # = not is_first
```

## 4. 各阶段函数定义

| 阶段 | 函数签名 | 输入 | 输出 | 说明 |
|------|--------|------|------|------|
| **1** | `stage1_parse_txt(txt_path: Path, interval_sec: float) -> pd.DataFrame` | `.txt` 路径 | 标准化 DataFrame | 列：`timestamp`, `delay_up`, `loss_up`, `delay_down`, `loss_down`；带宽=0 → loss=1.0 |
| **2** | `stage2_clean_and_truncate(df: pd.DataFrame, max_delay_ms: int) -> pd.DataFrame` | 原始 DataFrame | 清洗后 DataFrame | 截断首次 ≥max_delay 后所有行；非法值设为 NaN 后删除 |
| **3** | `stage3_split_and_resample(df: pd.DataFrame, max_gap_sec: float, min_rows: int, freq_hz: int = 10, max_invalid_ratio: float = 0.01) -> List[pd.DataFrame]` | 清洗后 DataFrame | 重采样段列表 | 时间戳对齐至 100ms 网格（`np.round(ts / 0.1) * 0.1`）；段内 gap ≤ max_gap_sec；loss 使用前向填充；非法 loss >1% 则丢弃整段 |
| **4** | `stage4_extract_windows(segments: List[pd.DataFrame], window: int, step: int) -> List[pd.DataFrame]` | 段列表 | 窗口列表（100×5） | 尾部不足丢弃；每窗口时间跨度 ≈9.9s |
| **5** | `stage5_mark_first_window(windows: List[pd.DataFrame], trace_id: str) -> List[WindowMetaRaw]` | 单文件窗口列表 + trace_id | `[{"window": df, "is_first": i==0, "start_time": ts, "trace_id": str}]` |
| **6** | `stage6_group_by_trace_id(all_metas: List[WindowMetaRaw]) -> Dict[str, List[WindowMetaRaw]]` | 全局窗口元数据 | `{trace_id: [metas...]}` | 聚合为 trace 级 |
| **7** | `stage7_assign_split_by_trace(traces: Dict[str, List], train_ratio=0.8, val_ratio=0.1, random_state=42) -> Tuple[List, List, List]` | trace 字典 | `(train_metas, val_metas, test_metas)` | **整 trace 划分**，保证 reproducible |
| **8** | `stage8_fit_and_normalize(train, val, test, random_state=42) -> Tuple[Dict[str, List[WindowMetaRenamed]], Dict]` | 三组 `WindowMetaRaw` | `(renamed_datasets, assets)` | 仅用 train 拟合 QuantileTransformer；重命名 `delay_up → del_up` 等；输出 `WindowMetaRenamed` |
| **9**| `stage9_recompute_condition_vectors(datasets: Dict[str, List[WindowMetaRenamed]], assets: Dict, network_state_map: Dict[str, int]) -> Tuple[Dict[str, List[WindowMetaNormed]], Dict]` | 归一化窗口 + 资产 | 更新后的 datasets（含 `cond`, `keep`） | **在归一化数据上构建 23 维条件向量；`keep = not is_first`** |
| **10** | `stage10_save_artifacts(datasets, assets, out_dir: Path, dtype=np.float32)` | 数据 + 资产 | 写入磁盘 | 仅保存 `keep=True` 样本 |
| **11**| `stage11_generate_report(stats: dict, config: dict, template_path: Path, out_path: Path)` | 统计指标 | 生成 `data_report.md` | 使用 Jinja2 |

> ✅ 所有函数**无全局状态、无磁盘写入（除 stage10）**，支持单元测试与并行化。

## 5. 条件向量（Condition Vector）—— 23 维（核心）

> 所有数值特征（除 `network_state_id`）在保存前已通过 **Level 2 Z-score 标准化**（基于训练集统计量）。

### 5.1 结构总览

🟢 **澄清类型语义**：维度 11 是整数类别 ID，但**以 float 形式存储**（如 `2.0`），供下游 embedding lookup 使用。

| 部分 | 维度范围 | 描述 | 数据类型 |
|------|--------|------|--------|
| **全局目标特征** | 0–12 | 描述当前窗口整体统计特性 | float (0–10), **int encoded as float (11)**, float (12) |
| **局部连续性特征** | 13–22 | 描述前一窗口结尾状态（最后5行） | float |

> 🔸 **总维度 = 23**  
> 🔸 **float 维度 = 22**（0–10, 12–22）  
> 🔸 **int 维度 = 1**（维度 11: `network_state_id`，**存储为 float**）  
> 🔸 **整个 `cond` 向量以 `np.float32` 存储**

---

### 5.2 第一部分：全局目标特征（13 维）

| idx | 特征名 | 含义 | 计算方式（基于当前窗口） | 实际实现 |
|-----|--------|------|------------------------|----------|
| 0 | `mean_del_up` | 上行 delay 均值（归一化后） | `np.mean(window["del_up"])` | ✅ 实现 |
| 1 | `std_del_up` | 上行 delay 标准差 | `np.std(window["del_up"])` | ✅ 实现 |
| 2 | `p1_del_up` | 上行 delay 1% 分位数 | `np.percentile(window["del_up"], 1)` | ✅ 实现 |
| 3 | `p99_del_up` | 上行 delay 99% 分位数 | `np.percentile(window["del_up"], 99)` | ✅ 实现 |
| 4 | `mean_del_dn` | 下行 delay 均值 | `np.mean(window["del_dn"])` | ✅ 实现 |
| 5 | `std_del_dn` | 下行 delay 标准差 | `np.std(window["del_dn"])` | ✅ 实现 |
| 6 | `p1_del_dn` | 下行 delay 1% 分位数 | `np.percentile(window["del_dn"], 1)` | ✅ 实现 |
| 7 | `p99_del_dn` | 下行 delay 99% 分位数 | `np.percentile(window["del_dn"], 99)` | ✅ 实现 |
| 8 | `frac_cat1_up` | 上行全丢包比例（简化为均值） | `np.mean(window["loss_up"])` | ✅ 实现 |
| 9 | `frac_cat1_dn` | 下行全丢包比例（简化为均值） | `np.mean(window["loss_dn"])` | ✅ 实现 |
|10 | `reserved1` | 保留位（设为 0.0） | `0.0` | ✅ 实现 |
|11 | `network_state_id` | **网络状态类别 ID（整数，存储为 float）** | **由外部提供（如文件名解析）** | ✅ 实现 |
|12 | `reserved2` | 保留位（设为 0.0） | `0.0` | ✅ 实现 |

> 📌 **注**：实际实现中简化了丢包分类，将所有非0的丢包值都设为1.0，只保留了全丢包比例（`frac_cat1_up` 和 `frac_cat1_dn`），其他丢包类别设为0.0。由于丢包值只有0和1两种，全丢包比例等于丢包均值。

> 📌 **注**：`network_state_id` **不由本流程生成**，需在原始 `.txt` 文件名或元数据中提供（如 `trace_001_state2.txt` → id=2）。若未提供，默认为 0。  
> 📌 **保留位当前固定为 0.0，未来扩展时需同步更新 `schema.json` 与模型输入层。**

### 5.3 第二部分：局部连续性特征（10 维）

🟢 **关键澄清**：因 `stage7` 保证**整 trace 在同一 split**，故“前一窗口”必在同一 split 内，**不存在跨 split 引用风险**。

| idx | 特征名 | 含义 | 计算方式（基于前一窗口最后5行） | 实际实现 |
|-----|--------|------|-------------------------------|----------|
|13| `prev_mean_del_up` | 上行 delay 均值 | `mean(last_5["del_up"])` | ✅ 实现 |
|14| `prev_std_del_up` | 上行 delay 标准差 | `std(last_5["del_up"])` | ✅ 实现 |
|15| `prev_frac_cat1_up` | 上行全丢包比例 | `mean(last_5["loss_up"])` | ✅ 实现 |
|16| `prev_reserved1_up` | 保留位（设为 0.0） | `0.0` | ✅ 实现 |
|17| `prev_reserved2_up` | 保留位（设为 0.0） | `0.0` | ✅ 实现 |
|18| `prev_mean_del_dn` | 下行 delay 均值 | `mean(last_5["del_dn"])` | ✅ 实现 |
|19| `prev_std_del_dn` | 下行 delay 标准差 | `std(last_5["del_dn"])` | ✅ 实现 |
|20| `prev_frac_cat1_dn` | 下行全丢包比例 | `mean(last_5["loss_dn"])` | ✅ 实现 |
|21| `prev_reserved1_dn` | 保留位（设为 0.0） | `0.0` | ✅ 实现 |
|22| `prev_reserved` | 保留位（设为 0.0） | `0.0` | ✅ 实现 |

> 📌 **注**：实际实现中简化了局部特征中的丢包分类，将所有非0丢包值设为1.0，只保留了全丢包比例（`prev_frac_cat1_up` 和 `prev_frac_cat1_dn`），其他丢包类别设为0.0。由于丢包值只有0和1两种，全丢包比例等于丢包均值。

> ✅ **首窗口处理**：  
> 若 `is_first=True`，则局部特征使用 `init_local_cond.npy`（10 维）填充维度 13–22。  
> `init_local_cond.npy` = **训练集中所有非末尾窗口（即可能作为前驱的窗口）的最后5行局部特征的均值**。

> ⚠️ **重要前提**：由于 `stage7` 保证**每个 trace 的所有窗口分配在同一 split**，因此在 `stage9` 中，每个非首窗的“前一窗口”必然存在于**同一 split 内**，无需跨 split 引用。

> ⚠️ **补充说明**：对于被分配到 val 或 test 的 trace，其在该 split 中的第一个窗口即使原始 `is_first=False`（即物理上不是文件首窗），也视为“逻辑首窗”，其局部特征使用 `init_local_cond.npy`。此时若 `keep=True`（因原始 `is_first=False`），该样本仍会被保留用于验证/测试，但其局部连续性特征来自冷启动统计均值，而非真实前驱状态。这是因无法获取跨 split 前驱而采取的合理近似。

## 6. 关键逻辑说明

### 6.1 时间戳对齐（阶段 3）
- 使用 NumPy 对齐：`df['timestamp'] = np.round(df['timestamp'] / 0.1) * 0.1`
- 对齐后去重，防止 round 导致重复时间戳
- **目的**：确保所有窗口严格对应 10Hz 采样率（100ms 间隔）

### 6.2 列名变更（阶段 8）
- `delay_up` → `del_up`
- `delay_down` → `del_dn`
- 阶段 9 及之后**不再出现 `delay_*` 列**

### 6.3 Level 2 Z-score 标准化（阶段 9）
- 仅对 **22 个 float 维度**（跳过 idx=11）计算均值/标准差
- 均值/标准差 **仅基于训练集**计算
- 标准化公式：`(x - cond_mean) / cond_std`
- 结果存为 `cond_mean.npy` 和 `cond_std.npy`

### 6.4 冷启动策略
- 推理时若无前一窗口，则局部特征 = `init_local_cond.npy`
- 该文件在训练阶段从 **训练集所有可能作为前驱的窗口**（即每个 trace 中除最后一个窗口外的所有窗口）的最后5行中统计得出

### 6.5 部分丢包均值资产
- `mean_loss_cat2_up.npy`：所有训练集中 `keep=True` 的窗口中满足 `0 < loss_up < 1` 的 loss 均值
- 用于推理时将“部分丢包”类别还原为连续值（如模型输出 cat=2 → 替换为此均值）
- 对称地提供 `mean_loss_cat2_dn.npy` 以支持未来扩展

## 9. 各阶段详细逻辑

### 9.1 阶段 1：`stage1_parse_txt`
- 跳过头部（从 `---` 行之后开始）
- 解析 `Start Time`（ISO8601）和 `Interval(sec)`
- 对每行 i（从 0 开始）：
  - `timestamp = start_ts + i * interval_sec`
  - `loss_up = 1.0 if Bandwidth1 == 0 else Loss1 / 100.0`
  - `loss_down = 1.0 if Bandwidth2 == 0 else Loss2 / 100.0`
- 返回列：`["timestamp", "delay_up", "loss_up", "delay_down", "loss_down"]`

### 9.2 阶段 2：`stage2_clean_and_truncate`
- 按 `timestamp` 排序、去重（记录 `non_monotonic_fixed`）
- 将 `delay < 0` 或 `loss ∉ [0,1]` 设为 NaN
- **从前往后扫描，首次出现 `delay_up ≥ max_delay_ms` 或 `delay_down ≥ max_delay_ms` → 丢弃该行及之后所有行**
- 删除含 NaN 的行

### 9.3 阶段 3：`stage3_split_and_resample`
- **时间戳对齐**（提升精度）：
  ```python
  df['timestamp'] = np.round(df['timestamp'] / 0.1) * 0.1
  ```
- **去重**（防止 round 后时间戳重复）：
  ```python
  df = df.drop_duplicates(subset=['timestamp']).reset_index(drop=True)
  ```
- 计算 `gap = timestamp.diff()`，若 `gap > max_gap_sec` → 切段
- 仅保留长度 ≥ `min_rows`（默认 200 行 = 20 秒 @10Hz）的段
- 重采样至 10Hz（100ms）：
  - `delay_up/down`：线性插值
  - `loss_up/down`：前向填充（forward fill）
- **非法值定义**：`loss ∉ [0,1]`
- **若重采样后非法比例 > `max_invalid_ratio`（默认 1%）→ 整段丢弃**
- 否则：`np.clip(loss, 0.0, 1.0)`

> ✅ 注意：非法值检测在 clip 之前进行，以确保数据质量评估基于原始重采样结果。

### 9.4 阶段 4：`stage4_extract_windows`
- 窗口长度 = 100 行（10 秒），步长 = 50 行（50% 重叠）
- **仅保留完整窗口（末尾不足 100 行的窗口丢弃）**

### 9.5 阶段 5：`stage5_mark_first_window`
- 输入：单文件所有窗口 + `trace_id = txt_file.stem`
- 输出：`[{"window": df, "is_first": i==0, "start_time": df.timestamp.iloc[0], "trace_id": trace_id}]`

### 9.6 阶段 6：`stage6_group_by_trace_id`
- 输入：所有 `WindowMetaRaw`（含 `trace_id`）
- 输出：`{trace_id: [meta1, meta2, ...]}`

### 9.7 阶段 7：`stage7_assign_split_by_trace`（**核心安全机制**）
- 输入：`{trace_id: windows}`
- **按 `trace_id` 随机打乱后划分**（保证 reproducible）：
  ```python
  trace_ids = list(traces.keys())
  rng = np.random.default_rng(random_state)
  rng.shuffle(trace_ids)
  n = len(trace_ids)
  n_train = int(n * train_ratio)
  n_val = int(n * val_ratio)
  train_ids = set(trace_ids[:n_train])
  val_ids = set(trace_ids[n_train:n_train+n_val])
  test_ids = set(trace_ids[n_train+n_val:])
  ```
- 分配：
  - `train_metas = [m for tid in train_ids for m in traces[tid]]`
  - 同理 val/test
- **优势**：同一 trace 所有窗口必在同一 split，避免 `stage9` 中局部特征跨 split 引用

### 9.8 阶段 8：`stage8_fit_and_normalize`
- **仅用 train_metas 中的窗口拟合 QuantileTransformer**
- **重命名 `delay_up → del_up`, `delay_down → del_dn`**
- **透传 `is_first`, `trace_id`, `start_time`**
- **输出类型为 `WindowMetaRenamed`（不含 `cond` 和 `keep`）**

### 9.9 阶段 9：`stage9_recompute_condition_vectors`

🟢 **重大澄清**：原 v1.2 未处理 val/test 中 trace 的第一个窗口（即使 `is_first=False`）的局部特征初始化问题。  
🟢 **v1.3 修正**：在每个 split 内，按 trace 分组后，**该 trace 在此 split 中的第一个窗口视为“逻辑首窗”**，使用 `init_local_cond.npy`。

- 对每个 split（train/val/test）：
  - 按 `trace_id` 分组
  - **组内按 `start_time` 升序排序**
  - 对每个窗口 i（从 0 开始）：
    - 若 `i == 0`（即该 trace 在此 split 中的第一个窗口）：
      - **无论其原始 `is_first` 是否为 True，均视为“逻辑首窗”**
      - 局部特征 = `init_local_cond.npy`
    - 否则：
      - 局部特征 = **前一窗口（同 trace，同 split，时间紧邻）的最后5行**
  - 构建 **23 维** `cond`（维度 11 为 `float(network_state_id)`）
  - `keep = not (原始 is_first)`
- **`init_local_cond.npy` 计算**：
  - 仅使用 **训练集**
  - 遍历每个 trace，取除最后一个窗口外的所有窗口（因为只有这些窗口会被用作“前驱”）
  - 对每个这样的窗口，提取其最后5行，计算 10 维局部特征
  - 对所有此类局部特征向量求均值 → `init_local_cond.npy`（shape=(10,)）

> ✅ 此设计确保：即使原始 `is_first=False`，但因 trace 被整体移动到 val/test，其在该 split 中成为“第一个窗口”，仍能正确初始化局部状态。

### 9.10 阶段 10：`stage10_save_artifacts`
- 仅保存 `keep=True` 的样本（即非首窗）
- 保存格式：JSONL（每行为一个 `WindowMetaNormed`，但仅含必要字段）

### 9.11 阶段 11：`stage11_generate_report`
- 包含字段：
  - 成功/失败/空文件数
  - Train/Val/Test 窗口数量（仅 `keep=True`）
  - 下行丢包分布（cat0/cat1/cat2 比例）
  - `mean_loss_cat2_up` 估计值（仅基于训练集 `keep=True` 样本）
  - 处理时间戳

```python
# main.py (v1.3)
from pathlib import Path
import yaml, json, numpy as np, re
from datetime import datetime, timezone
from tqdm import tqdm
from src.preprocessing import *

def main():
    with open("config.yaml") as f:
        cfg = yaml.safe_load(f)
    
    # 自动填充 output_dir 时间戳（UTC）
    if "<auto>" in cfg["output_dir"]:
        auto_name = datetime.now(timezone.utc).strftime("%Y%m%d_%H%M%S_UTC")
        cfg["output_dir"] = cfg["output_dir"].replace("<auto>", auto_name)
    
    out_dir = Path(cfg["output_dir"])
    out_dir.mkdir(parents=True, exist_ok=True)
    (out_dir / "assets").mkdir(parents=True, exist_ok=True)
    (out_dir / "meta").mkdir(parents=True, exist_ok=True)

    # 构建 network_state_map
    pattern = cfg.get("filename_pattern", ".*_state(\\d+)\\.txt")
    default_id = cfg.get("default_network_state_id", 0)

    all_windows_meta = []
    failed_files = []
    empty_files = []

    txt_files = list(Path(cfg["input_dir"]).glob("*.txt"))
    network_state_map = {}
    for txt_file in txt_files:
        match = re.search(pattern, txt_file.name)
        network_state_map[txt_file.stem] = int(match.group(1)) if match else default_id

    for txt_file in tqdm(txt_files, desc="Processing files"):
        try:
            df_raw = stage1_parse_txt(txt_file, cfg["raw_interval_sec"])
            df_clean = stage2_clean_and_truncate(df_raw, cfg["max_delay_ms"])
            segments = stage3_split_and_resample(
                df_clean,
                max_gap_sec=cfg["max_gap_sec"],
                min_rows=cfg["min_segment_rows"],
                max_invalid_ratio=cfg.get("max_invalid_ratio", 0.01)
            )
            windows = []
            for seg in segments:
                windows.extend(stage4_extract_windows(seg, cfg["window_size"], cfg["step_size"]))
            
            if not windows:
                empty_files.append(str(txt_file))
                continue

            trace_id = txt_file.stem
            window_metas = stage5_mark_first_window(windows, trace_id)
            all_windows_meta.extend(window_metas)

        except Exception as e:
            failed_files.append(f"{txt_file}: {str(e)}")
            continue

    # 保存失败/空文件
    if failed_files:
        with open(out_dir / "meta" / "failed_files.txt", "w") as f:
            f.write("\n".join(failed_files))
    if empty_files:
        with open(out_dir / "meta" / "empty_files.txt", "w") as f:
            f.write("\n".join(empty_files))

    # 聚合为 trace 级
    traces_dict = stage6_group_by_trace_id(all_windows_meta)
    
    # 按 trace 划分（整 trace 分配）
    train, val, test = stage7_assign_split_by_trace(
        traces_dict,
        train_ratio=cfg["split"]["train"],
        val_ratio=cfg["split"]["val"],
        random_state=cfg["split"]["random_state"]
    )

    # 归一化 + 列重命名
    renamed_datasets, assets = stage8_fit_and_normalize(
        train, val, test, random_state=cfg["quantile_transformer"]["random_state"]
    )

    # 重建条件向量（基于归一化数据，标记 keep）
    final_datasets, extra_assets = stage9_recompute_condition_vectors(
        renamed_datasets, assets, network_state_map
    )
    assets.update(extra_assets)

    # 保存（自动过滤 keep=False）
    stage10_save_artifacts(
        final_datasets, assets, out_dir, dtype=getattr(np, cfg["output_dtype"])
    )

    # 写入 schema.json
    schema = {
        "pipeline_version": "v1.3",
        "columns": ["timestamp", "del_up", "del_dn", "loss_up", "loss_dn"],
        "window_size": cfg["window_size"],
        "freq_hz": 10,
        "normalized": True,
        "condition_vector_dim": 23,
        "condition_vector_structure": {
            "global_features": list(range(13)),
            "local_features": list(range(13, 23))
        },
        "network_state_id_source": "filename_regex_or_default",
        "network_state_id_encoding": "integer category stored as float (e.g., 2.0)",
        "level2_normalization": "Z-score normalization applied to 22 float dimensions (indices 0–10 and 12–22), excluding the integer-encoded network_state_id at index 11.",
        "split_strategy": "Entire traces are assigned to a single split to prevent data leakage.",
        "normalization": {
            "del_up/del_dn": "QuantileTransformer(output_distribution='normal'), fitted on train set",
            "loss_up/loss_dn": "Clipped to [0.0, 1.0], no transformation applied"
        }
    }
    with open(out_dir / "meta" / "schema.json", "w") as f:
        json.dump(schema, f, indent=2)

    # 报告统计（仅 keep=True）
    total_train = sum(1 for w in final_datasets["train"] if w["keep"])
    total_val = sum(1 for w in final_datasets["val"] if w["keep"])
    total_test = sum(1 for w in final_datasets["test"] if w["keep"])

    stats = {
        "total_windows": total_train + total_val + total_test,
        "train_count": total_train,
        "val_count": total_val,
        "test_count": total_test,
        "processed_files": len(txt_files),
        "failed_files": len(failed_files),
        "empty_files": len(empty_files),
        "timestamp": datetime.now(timezone.utc).isoformat()
    }
    stage11_generate_report(stats, cfg, Path(cfg["report_template"]), out_dir / "data_report.md")

if __name__ == "__main__":
    main()
```
