# 📝 NetFaker 日志模块设计文档

> 基于 `loguru` 实现统一、安全、可配置的日志系统  
> 最后更新：2026-01-21

---

## 一、设计目标

- ✅ **统一格式**：所有模块输出风格一致  
- ✅ **灵活输出**：支持控制台 + 文件双通道  
- ✅ **自动轮转**：防止单文件过大，自动清理旧日志  
- ✅ **环境隔离**：开发/生产通过 `.env` 切换行为  
- ✅ **安全写入**：支持多进程、异步场景（FastAPI）  
- ✅ **零侵入使用**：任意模块 `from loguru import logger` 即用

## 三、配置项说明

通过 `.env` 文件或环境变量控制日志行为：

| 变量名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `LOG_LEVEL` | string | `"INFO"` | 日志级别：`DEBUG`, `INFO`, `WARNING`, `ERROR` |
| `LOG_TO_FILE` | bool | `true` | 是否写入文件（`true`/`false`） |
| `LOG_DIR` | path | `"logs"` | 日志目录（相对或绝对路径） |

### 示例 `.env`

```ini
# 开发环境
LOG_LEVEL=DEBUG
LOG_TO_FILE=false

# 生产环境
LOG_LEVEL=WARNING
LOG_TO_FILE=true
LOG_DIR=/var/log/netfaker
```

## 四、核心实现

### 1. 配置模型（`src/netfaker/core/config.py`）

```python
from pathlib import Path
from pydantic_settings import BaseSettings

class Settings(BaseSettings):
    LOG_LEVEL: str = "INFO"
    LOG_TO_FILE: bool = True
    LOG_DIR: Path = Path("logs")

    class Config:
        env_file = ".env"
        env_file_encoding = "utf-8"

settings = Settings()
```

### 2. 日志初始化（`src/netfaker/core/logger.py`）

```python
import sys
from pathlib import Path
from loguru import logger
from .config import settings

def setup_logger() -> None:
    """初始化全局日志器"""
    logger.remove()

    # 控制台输出（带颜色）
    logger.add(
        sys.stderr,
        level=settings.LOG_LEVEL,
        format="<green>{time:YYYY-MM-DD HH:mm:ss}</green> | "
               "<level>{level: <8}</level> | "
               "<cyan>{name}</cyan>:<cyan>{function}</cyan>:<cyan>{line}</cyan> - "
               "<level>{message}</level>",
        enqueue=True,
        colorize=True,
    )

    # 文件输出（按需开启）
    if settings.LOG_TO_FILE:
        log_dir = Path(settings.LOG_DIR)
        log_dir.mkdir(parents=True, exist_ok=True)
        logger.add(
            log_dir / "netfaker_{time:YYYYMMDD}.log",
            level=settings.LOG_LEVEL,
            rotation="100 MB",
            retention="7 days",
            encoding="utf-8",
            enqueue=True,
            format="{time:YYYY-MM-DD HH:mm:ss} | {level: <8} | {name}:{function}:{line} - {message}",
        )
```

### 3. 应用启动（`src/netfaker/app/main.py`）

```python
from fastapi import FastAPI
from netfaker.core.logger import setup_logger
from loguru import logger

setup_logger()  # 必须在 app 创建前调用

app = FastAPI(title="NetFaker API")
logger.info("NetFaker 服务启动成功")
```

## 五、使用规范

### 在任意模块中记录日志

```python
from loguru import logger

def simulate_task():
    logger.debug("开始解析输入参数")
    logger.info(f"使用策略: rule")
    logger.warning("检测到低质量输入数据")
    logger.error("仿真生成失败")
    logger.success("任务完成，配置文件已生成")
```

> 🔹 支持 `loguru` 特有级别：`success`, `trace`  
> 🔹 所有日志自动包含时间、模块名、函数名、行号

## 六、运维建议

| 场景 | 建议 |
|------|------|
| **本地开发** | `LOG_TO_FILE=false`，仅看控制台 |
| **Docker 部署** | 挂载卷：`-v /host/logs:/var/log/netfaker` |
| **磁盘空间** | 保留策略 `7 days` + 轮转 `100 MB` 可控 |
| **日志收集** | 文件格式为纯文本，兼容 Filebeat / Fluentd |

---

## 七、注意事项

- ❗ **必须在创建 FastAPI app 前调用 `setup_logger()`**
- ❗ 不要手动创建多个 `logger` 实例，始终使用全局导入
- ❗ 生产环境避免 `DEBUG` 级别，防止敏感信息泄露
- ✅ 日志文件自动按 **日期 + 大小** 轮转，无需额外脚本
