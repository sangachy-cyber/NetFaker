# 🧩 NetFaker 边界感知拼接后处理模块设计方案  
**版本：2.1（最终版 · 状态感知 · 通道差异化）**

---

## 一、设计目标

> **在严格保留窗口内部结构与真实状态跃迁的前提下，仅对同状态窗口间因独立抽样导致的非物理边界不连续进行最小干预，显著改善时序自相关性（ACF），同时保护丢包突发性（burst）与联合一致性。**

### 核心原则
- ✅ **状态感知**：仅同状态内处理，不同状态保留原始跃迁  
- ✅ **通道差异化**：时延用 Hann 局部混合，丢包仅做事件延续  
- ✅ **最小干预**：每窗口最多修改前 5 个点，95% 数据原样保留  
- ✅ **零合成值**：丢包率绝不插值，只复制真实观测值  

---

## 二、问题背景

NetFaker 采用“独立窗口抽样 + 拼接”策略，虽高效但存在：
- **同状态窗口边界出现非物理跳跃**（如 delay: 92ms → 50ms）
- 导致 **`acf_mae_lag1_10` 通过率仅 51.1%**
- 早期“整体偏移”方案失败：因引入全局漂移，破坏分布并恶化 KS

> 🔍 根本原因：**未区分状态，且对丢包误用数值平滑**

---

## 三、解决方案：状态感知双通道边界修复

### 处理逻辑总览

| 条件 | 时延（delay） | 丢包率（loss） |
|------|---------------|----------------|
| **`state_i == state_{i+1}`** | ✅ Hann 局部混合（前 5 点） | ✅ 事件延续（复制值） |
| **`state_i != state_{i+1}`** | ❌ 不处理 | ❌ 不处理 |

> 所有操作仅作用于**下一窗口的前 N 点**，不改变窗口长度（仍为 100 点）

---

## 四、详细处理策略

### 4.1 时延通道：Hann 局部混合（仅同状态）

#### 触发条件
- `state_ids[i] == state_ids[i+1]`

#### 操作
- 取重叠长度 `L = 5`
- 计算 Hann 权重：
  ```python
  hann_in  = [0.0, 0.345, 0.750, 0.955, 1.0]   # 淡入
  hann_out = [1.0, 0.955, 0.750, 0.345, 0.0]   # 淡出
  ```
- 更新下一窗口前 5 点：
  ```python
  next_win[:5] = hann_out * curr_win[-5:] + hann_in * next_win[:5]
  ```

#### 效果
- 边界完全平滑（无阶跃）
- 窗口主体（95 点）100% 保留 → ACF/PSD 不受损

---

### 4.2 丢包通道：事件延续（仅同状态 + burst 中断）

#### 触发条件（需同时满足）
1. `state_ids[i] == state_ids[i+1]`
2. `loss_windows[i][-1] > BURST_THR`（默认 5.0%）
3. `loss_windows[i+1][0] <= BURST_THR`

#### 操作
- 获取上一窗口末尾丢包值：`last_val = loss_windows[i][-1]`
- 覆盖下一窗口前 `K` 点（默认 `K=2`）：
  ```python
  loss_windows[i+1][0] = last_val
  loss_windows[i+1][1] = last_val   # 若长度 ≥2
  ```

#### 示例
**原始**：
```
W_i:     [..., 0, 0, 22.1]
W_{i+1}: [0, 0, 0, 18.3, ...]   ← burst 被错误中断
```
**处理后**：
```
W_{i+1}: [22.1, 22.1, 0, 18.3, ...]   ← burst 正确延续
```

> ⚠️ **绝不进行加权平均、插值或 Hann 混合**——只复制真实值

---

## 五、输入与输出

### 输入
- `delay_windows`: List[np.ndarray], shape=(N, 100)
- `loss_windows`: List[np.ndarray], shape=(N, 100)
- `state_ids`: List[int], length=N（由 Trace Analyzer 提供）

### 输出
- 同形状的 `delay_windows` 和 `loss_windows`
- 仅部分窗口的**前 1~5 个点被修改**
- **窗口数量、长度、主体内容不变**

## 六、模块集成

### 目录结构
```
src/netfaker/simcore/
 └── postprocessing/
     └── boundary_stitcher.py    # StateAwareStitcher 类
```

### 调用方式
```python
if settings.enable_boundary_smoothing:
    stitcher = StateAwareStitcher(
        overlap_points=5,
        loss_continuation_points=2,
        loss_burst_threshold=5.0
    )
    delay_windows = stitcher.smooth_delay(delay_windows, state_ids)
    loss_windows = stitcher.extend_loss_bursts(loss_windows, state_ids)
```

### 配置（`.env`）
```ini
ENABLE_BOUNDARY_SMOOTHING=true
BOUNDARY_OVERLAP_POINTS=5
LOSS_CONTINUATION_POINTS=2
LOSS_BURST_THRESHOLD_PCT=5.0
```

## 七、关键设计决策

| 决策 | 理由 |
|------|------|
| **必须依赖 state_ids** | 避免平滑真实状态跃迁（如 s2→s5） |
| **Hann 仅用于 delay** | loss 是离散事件，平滑会制造非物理值 |
| **overlap=5（500ms）** | 平衡平滑性与保真度，符合网络动态尺度 |
| **loss 延续 2 点** | 防止 burst 被单点噪声打断 |
| **阈值与评估模块一致** | 确保训练-评估对齐 |

## 十、总结

本方案是 **精准、安全、高效** 的边界修复策略：
- **精准**：仅修同状态内的非物理抖动  
- **安全**：不同状态跃迁原样保留，丢包绝不合成  
- **高效**：计算开销极小，无缝嵌入现有 pipeline  

> 启用后，NetFaker 生成的 HoloWAN 文件将实现：  
> **“同状态内平滑自然，状态切换时锐利真实”** —— 这正是高质量网络仿真数据的核心特征。
